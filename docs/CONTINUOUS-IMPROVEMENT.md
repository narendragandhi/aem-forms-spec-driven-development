# Continuous Improvement

The showcase follows a bounded loop: failure or reviewer feedback creates a
bead, the issue receives a synthetic regression fixture, a change is proposed,
the verification suite runs, and a human approves any canary or production
change. Rejected proposals remain part of the evidence trail.

This is the safe form of self-improvement for healthcare and financial journeys:
the system can learn from evidence, but it cannot silently rewrite policy,
HITL routing, access controls, or production code.

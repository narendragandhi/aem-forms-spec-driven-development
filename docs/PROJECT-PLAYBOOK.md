# Reusable AEM Forms Showcase Playbook

This showcase is the reference implementation of the archetype’s reusable
project playbook. For a new project, keep the delivery loop and replace the
project profile, scenarios, form model, rules, integrations, and evidence.

Start with the archetype documents `PROJECT-PLAYBOOK.md`,
`PRESENTATION-RUNBOOK.md`, and `NEW-PROJECT-CHECKLIST.md`. The healthcare and
financial journeys here are examples, not mandatory domain behavior. Use
synthetic data in public demos and keep production evidence, credentials, PHI,
and customer-specific configurations private.

# Residuality Design in the Showcase

The showcase applies Residuality Theory to the healthcare and financial journeys.
Its stressors, incidence matrix, residues, and attractors are the architectural
bridge between demo behavior and chaos engineering. Start with the archetype
catalog, then add domain-specific stressors without using real personal data.

The most important invariants are: accepted applications remain traceable,
duplicate submissions do not create duplicate agreements, human review cannot be
bypassed, and signed documents remain linked to the source decision.

Each experiment belongs in a bead and must produce a regression fixture or an
explicit operational remediation. A failure is useful evidence; an unrecorded
failure is not a learning loop.

# SOC 2 Readiness

The showcase is not SOC 2 compliant or certified. It is a demonstrator with
technical control patterns and evidence-oriented documentation. SOC 2 requires
an in-scope system description, operated controls, evidence over time, and an
independent examination.

For the current implementation, the main gaps are organizational access reviews,
change approvals, incident exercises, vendor risk, backup/restore evidence,
production monitoring, real webhook replay protection, and independent review.

Use the archetype’s `docs/compliance/` pack as the starting control register for
projects generated from this showcase. Keep audit evidence and any real customer
or healthcare data outside Git.

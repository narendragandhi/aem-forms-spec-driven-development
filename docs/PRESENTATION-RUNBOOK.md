# Showcase Presentation Runbook

Use the healthcare scenario for a product-manager presentation:

1. Open seeded demo mode and identify the use case and actors.
2. Trigger the adaptive rule and explain the business decision.
3. Submit and show policy evaluation.
4. Pause at HITL, approve once, then repeat with rejection for follow-up.
5. Walk through the status timeline, architecture panel, correlation ID, and
   observability contract.
6. Show the archetype and beads as the repeatable delivery mechanism.

State explicitly that seeded evaluation, HITL, signature, and DoR behavior is
deterministic demo behavior unless live environment evidence is attached.
